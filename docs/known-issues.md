## 开发态 macOS 钥匙串反复授权弹窗

- **日期：** 2026-08-10
- **状态：** 暂缓；正式签名包与更稳的钥匙串 ACL 策略后再处理
- **现象：**
  - 登录后冷启动仍多次弹出钥匙串授权
  - 点「始终允许」后，同一次启动仍可能多次弹出
  - 跨重启因 ad-hoc 签名授权不持久，弹窗会再次出现
- **已知缓解：** 已有进程内 Credential 缓存（`CachedCredentialStore` / `TauriCredentialStore`），可减少同会话重复访问，但不能消除冷启动或签名变更导致的系统弹窗
- **关联症状：** 冷启动若钥匙串授权被取消/失败，首页与侧栏会空白；现已用连接健康点 + 明确失败文案 + 重试拉取库内容，仍不消除系统弹窗本身
- **处理方向（未排期）：** 正式签名 / 公证包，以及更稳的钥匙串 ACL 策略
